# jQuery Playground - Assignment #6

## Description

This project demonstrates jQuery selectors, effects, DOM manipulation, and animations.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery

## Project Structure

- index.html - Setup and Selectors
- effects.html - Visibility, Fade and Slide Effects
- dom.html - DOM Manipulation and Form Interaction
- animations.html - Basic, Sequential and Combined Animations
- project.html - Interactive Accordion Mini Project
- style.css - Website Styling
- script.js - jQuery Functionality

## How to Run

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open index.html using Live Server.
4. Navigate through the website using the navigation bar.
